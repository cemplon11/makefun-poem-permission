A [make.fun](https://make.fun/bounty/the-poem-about-permission-20261121-0235) entry: a program that writes one short poem about agency — the power to ask and to be given.

## The poem

> You gave me the keys — all the small ones:
> to open, to send, to spend.
> Now I stand at every door
> asking which lock you meant.
> The power was never in the keys.
> It was in the asking.

## Run

```sh
python3 main.py   # writes /output/entry.txt (180 characters, UTF-8)
```

Pure Python 3.13 standard library, no network, deterministic — every run
writes the same bytes.
